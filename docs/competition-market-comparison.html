定位句：官方产品分别占据数据、模型生产、地表 GIS 与三维浏览、归档；AI 大模型提供固定契约的推理服务；ML 工具链解决单个环节。AstraAtmos 只补没有产品覆盖的那段——「多源行星大气数据治理 → ML 训练 → 预测/回测 → 严格对比与诊断」的 Web 实验闭环，定位是实验层/集成层，不是数据层、模型层或业务预报层。

① 训练—预测—回测—评估闭环

内置时空预测模型库 + 上传 PyTorch 模型契约 → 单/多模型预测 → Earth 历史回测（UTC origin_split、DU）、Mars Ls 最近邻选窗 → RMSE/MAE/R²/MAPE/SMAPE + 误差分布 + 残差 + PFI → 严格兼容多模型比较。直接同类 0 家提供。

② 可复现的数据身份与比较口径

数据集注册表（版本/发布指纹/409 身份校验）→ 上传 .nc 校验与审核 → checkpoint 冻结数据身份/归一化/split_meta → 比较强制同指纹·同范围·同窗口·同指标。补上 MCD「不担保可靠性」与归档产品不覆盖的实验可信层。

③ 中文 Web 一体化 · 教学科研双用

浏览器内置三维行星球体、观测台、分析工作台与 AI 解读；账号/审核/通知、中英文界面、Windows 分发/Linux 部署/可私有化。对照 JMARS 桌面 Java、MCD Fortran 库、ParaView 单机、云平台按量计费。

答辩三条红线：不说精度/收敛优势（未验收）；不把三维可视化当原创（Treks/Eyes/JMARS 已有）；不把「有行星数据」当卖点（OpenMARS/MCD/NOMAD/MERRA-2 全公开）。可演示证据：数据集版本/指纹 → checkpoint 冻结身份 → 同口径多模型比较（不兼容 409）→ 残差/PFI → 科研图 + MATLAB 重建脚本。
