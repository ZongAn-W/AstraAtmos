# 训练模型多标签分组

标签用于整理训练记录，每条记录的参数、权重、指标仍属于原任务。一个任务可带多个标签，标签按账号私有，并持久保存在数据库中。

## 使用方式

1. 在训练页面的模型名称下选择“训练标签”，可搜索已有标签或直接新建。标签可留空，任务运行中、成功或失败后仍可调整。
2. 在历史记录中通过模型名称、标签筛选定位模型。多个标签必须同时满足；“全部”清除标签条件，“未分组”显示当前账号未标记的记录。名称搜索可叠加使用。
   历史卡片默认只展示输入/输出窗口、轮数、批大小和学习率等摘要；点击“查看参数”后再展开完整参数，自定义模型参数按键值列表查看。
3. 使用卡片的“编辑标签”替换单个任务的标签。勾选多条记录后可批量添加或移除指定标签，不影响其他标签；改变筛选条件会清空批量勾选。
4. “管理标签”支持新建、重命名和删除。删除前会提示：该标签从自己标记的所有记录中移除，模型、参数、日志和权重均保留。
5. 预测页的单模型和多模型对比也可按标签筛选。已有选择保留，筛选外的当前模型或已选数量会显示。多模型对比的“全选当前结果”追加当前可见模型，“清空选择”移除全部选择。

标签名称去除首尾空格后为 1–64 个字符。同一账号内使用 Unicode `casefold()` 后的名称不可重复，不同账号可以使用相同名称。前端提供基本名称检查，服务端校验为最终依据。

## 权限与存储

- 普通用户只能标记自己的任务；管理员可以标记所有当前有权访问的任务。管理员的标签同样私有，不会改变任务所有者的标签。
- `training_model_tags` 保存用户、标签名称、规范化名称和创建时间，`(user_id, name_key)` 唯一；`training_task_tags` 保存 `(task_id, tag_id)` 联合唯一的关联。
- 现有数据库通过启动时的 `Base.metadata.create_all()` 创建新增表，旧记录默认未分组。本功能不回填超参数、不搬迁权重、不改变预测缓存键或产物指纹。
- 删除任务时清理所有用户对此任务的标签关联，标签本身保留；删除标签时仅清理该标签及关联。
- 任务列表按当前访问账号批量附加标签，避免逐条读取；退出或切换账号时清空标签、筛选和批量选择。旧列表响应不能覆盖较新的刷新结果。

## API

以下接口均要求认证，路径前缀为 `/api/training`。标签对象为 `{ "id": 1, "name": "沙尘实验" }`。

| 方法与路径 | 请求 | 响应 |
| --- | --- | --- |
| `GET /tags` | 无 | 当前账号的标签数组 |
| `POST /tags` | `{ "name": "沙尘实验" }` | 新建标签对象 |
| `PATCH /tags/{tag_id}` | `{ "name": "基线实验" }` | 更新后的标签对象 |
| `DELETE /tags/{tag_id}` | 无 | `{ "status": "success" }` |
| `PUT /tasks/{task_id}/tags` | `{ "tag_ids": [1, 2] }` | 带当前账号标签的任务对象；空数组清空自己的标记 |
| `PATCH /task-tags` | `{ "task_ids": [10, 11], "tag_ids": [1], "operation": "add" }` | 修改后的任务数组；`operation` 为 `add` 或 `remove` |

`POST /start` 增加可选 `tag_ids`，默认 `[]`；任务创建与标签关联在同一事务中提交，然后调度训练子进程。启动、列表、重命名和标签修改返回的任务对象均包含 `tags` 数组，内容只属于当前账号。标签不放进 `hyperparameters`。

批量接口先验证全部任务权限和标签归属，再在一个事务中提交；重复添加或移除是幂等操作，失败不会保留部分修改。不存在或其他账号的标签返回 404，不可访问的任务返回 403，同账号标签重名返回 409，字段格式或长度错误返回 422。没有认证沿用现有认证错误响应。

SQLite 标签写操作在权限校验前显式开启写事务，防止并发删除或 ID 复用改变已校验的归属；创建和重命名返回已提交的对象，避免提交后的再次读取取到其他账号复用同一 ID 的标签。

## 验证入口

- 后端：从 `AstraAtmos_backend/backend/` 运行 `python -m pytest tests/test_training_tags.py`，覆盖持久化、权限、事务、训练启动、清理及缓存身份不变。
- 前端：从 `frontend/` 运行 `node --test` 和 `npm run build`；标签筛选与请求顺序测试位于 `src/components/TrainingTags/`，API 契约测试位于 `src/services/api.trainingTags.test.js`。
- 界面检查应包含：多标签交集、未分组、搜索组合、批量操作、编辑与删除、刷新、预测选择保留、账号切换，以及中英文和明暗主题。可使用测试任务与模拟训练启动完成检查，无需训练真实模型。
